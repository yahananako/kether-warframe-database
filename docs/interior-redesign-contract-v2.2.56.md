# KETHER 分頁重製硬規格 · v2.2.56

> 首頁（`/`）為已驗收母版，封存不改。以下規格適用於首頁以外的所有頁面。

## 四條硬規則

1. **單一視窗，自適化，不允許頁面上下捲動**
   - 所有分頁固定在 `100dvh`。
   - `html` / `body` / `SiteShell` 均禁止垂直捲動。
   - 內容超量時必須改成分頁、頁籤、卡片切換、左右切換或分區切換，不能靠往下滑。
   - 桌機、筆電、平板與手機都遵守同一原則。

2. **每一頁共用首頁背景特效**
   - 同一支 KETHER 背景影片與 poster。
   - 共用 Canvas 粒子、漂浮光點、極光、體積光、光束、網格。
   - 青色操作光、金色提示光與首頁一致。
   - `prefers-reduced-motion` 仍保留無障礙降動態處理。

3. **固定上區塊與下區塊**
   - 上區塊：KETHER Logo／名稱、選單、通知、Discord 登入。
   - 上區塊下方固定 KETHER 動態資訊跑馬燈。
   - 下區塊：共同開發者、正式網址、版本與資料來源。
   - 所有分頁固定存在，不能由單一頁面自行刪除或改版。
   - 中間只有「頁面工作區」可以替換。

4. **首頁以外全部重新設計**
   - 不把目前的普通深色卡片頁當成最終樣式。
   - 所有分頁的資訊層級、互動、卡片、分類、按鈕與動態效果重新設計。
   - 設計方向只能「分頁追首頁」，禁止「首頁追分頁」。

## 共用框架

`components/SiteShell.tsx` 是所有非首頁頁面的唯一外框：

```
100dvh
├─ 固定上區塊
├─ 固定動態資訊
├─ 自適化工作區（overflow: hidden）
└─ 固定下區塊
```

工作區若內容超過可視高度，該頁必須重構資訊架構，不得打開 body/page 垂直 scrollbar。

## 驗收條件

每一頁完成時都必須確認：

- 沒有瀏覽器垂直 scrollbar。
- 1366×768、1440×900、1920×1080 能完整操作。
- 手機尺寸以重新排版／切頁方式容納，不用上下捲整頁。
- 上區塊、跑馬燈、下區塊都存在。
- 背景影片與首頁同源，光效語言一致。
- hover / focus / active 都有可見回饋。
- 功能與資料不能因視覺重製而消失。
