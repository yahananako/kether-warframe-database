# KETHER 全站介面重製 · 2.2.53

本次從共用介面與各頁樣式來源重建，統一深藍底、青色操作、金色提示、字級、間距、卡片與表單。首頁、資料庫、故事書、氏族、個人、BOT、即時情報、通知、登入與管理介面使用同一套導覽與頁尾。

## 實作

- 根版型使用 `SiteShell`：導覽、搜尋、通知、手機選單、跑馬燈、背景與版本資訊集中維護。遵守減少動態效果設定，頁面不可見時暫停背景影片。
- 移除各頁重複頁首、頁尾；重新整理全域樣式，並直接更新各功能 CSS modules，保留各頁必要的閱讀與操作結構。
- 搜尋涵蓋既有表格、一般戰甲與靈化資料；提供分類總數、每頁 24 筆的分頁、搜尋別名與資料來源失敗提示。一般戰甲連到詳細頁，靈化結果帶入對應武器搜尋。
- 戰甲頁預設顯示全部戰甲；手機資料表改為卡片。新增共用載入、錯誤與找不到頁面狀態。
- 故事原圖載入失敗時，顯示中性缺圖狀態；沒有以不相關圖片替代原作。
- 權限檢查、Discord 登入同意條件、收藏保存、BOT API、管理員權限與視覺編輯流程沿用既有邏輯。

## 驗證與限制

- `npm run build`：包含 TypeScript 與 255 個靜態頁面產生。
- 32 條代表路由，以 1440 × 900 與 390 × 844 檢查頁面載入、共用頁首、橫向溢出與 JavaScript 執行錯誤。
- 瀏覽器互動涵蓋登入五項閱讀與勾選、桌面懸停選單、通知、首頁搜尋、搜尋下一頁、戰甲篩選、靈化深層連結、故事圖片失敗狀態及編輯器畫面。
- 本機測試使用明確隔離的測試 session。編輯器畫面以唯讀 API fixture 驗證，未呼叫儲存或發布。
- 本機沒有正式 Discord / Supabase 憑證；真實 OAuth、個人資料寫入與管理員發布需要正式環境驗收。建置後 Discord 指令同步因未設定憑證而正常略過。
- 官方故事圖 URL 以 HTTP 取得成功，但測試 Chromium 的直接請求收到 `ERR_EMPTY_RESPONSE`；已驗證缺圖顯示，沒有聲稱瀏覽器已成功下載外部原圖。
